# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public GitHub Issue for suspected security vulnerabilities.

Until a dedicated security contact is published, report the issue privately to the repository owner through GitHub. Include:

- affected version or commit
- clear reproduction steps
- security impact
- suggested remediation, if known

Do not include real customer data, credentials, API keys, tokens, or other sensitive information.

## Scope

SiberKOBİ is a self-assessment application. It does not require user accounts, persistent storage, external AI services, or third-party API credentials in its initial release.

Security reports should focus on the application itself, its container image, dependencies, or release artifacts.
